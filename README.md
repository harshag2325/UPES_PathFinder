Pathfinder in UPES
Overview
Pathfinder in UPES is a campus navigation project designed to help
students, faculty, staff, and visitors find efficient routes across the
UPES Bidholi campus.

Inspired by navigation platforms such as Google Maps, the project uses
the A* (A-Star) search algorithm and a graph-based data
structure to calculate optimal paths between campus locations. Its
goal is to make campus navigation easier, faster, and more convenient.
Features
- Shortest Path Calculation: Uses the A* algorithm to find an
  efficient route between a selected starting point and destination.
- Mode-Specific Routing: Supports different routing modes,
  including pedestrian and vehicle-based navigation.
- Campus Map Visualization: Displays a detailed map of the UPES
  campus, including landmarks and calculated routes.
- Step-by-Step Guidance: Provides clear, turn-by-turn directions
  to help users follow the selected route.
- User-Friendly Interface: Offers a simple console-based interface
  for entering starting points, destinations, and travel preferences.

Project Goal
The primary goal of Pathfinder in UPES is to improve the campus
navigation experience through algorithm-based route optimization and
clear visual guidance. By making it easier to locate destinations and
choose efficient paths, the project aims to support a more accessible
and connected campus.
